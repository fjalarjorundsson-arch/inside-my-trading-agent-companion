# Companion code for *Inside My Trading Agent*

By Fjalar Jörundsson. Standard-library Python 3.9+; no API keys, no accounts,
no network access beyond your own `localhost`. MIT licence (see `LICENSE`).

| File | Book section | Run |
|---|---|---|
| `starter_report.py` | Appendix B | `python starter_report.py` |
| `test_starter_report.py` | Appendix B | `python -m unittest -v test_starter_report.py` |
| `benchmark_local_model.py` | Chapter 13 | `python benchmark_local_model.py --model <id> --runs 20` |

All prices, dates, companies and evidence in these files are synthetic. Nothing
here is investment advice, and nothing here can place an order.
